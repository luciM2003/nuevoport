# Lucía Miranda · Portfolio

Bilingual portfolio (English and Spanish) of Lucía Miranda, Senior UX/UI & Product Designer.
Live at https://lucim2003.github.io/nuevoport/

## How it works

Plain HTML, CSS and JavaScript, generated by a small Node script with no dependencies. GitHub Pages serves the `main` branch from the repository root, so the generated pages are committed.

```
src/content    site data, résumé facts, project list
src/cases      case studies, written once in both languages: t('English', 'Español')
src/pages      page templates
src/styles     design tokens and styles
src/client     progressive enhancement (the site works without JavaScript)
scripts        build, checks, images, share previews
cv             résumé in English and Spanish
```

| Command | What it does |
| --- | --- |
| `npm run dev` | Builds and serves the site at http://localhost:3000 |
| `npm run build` | Regenerates every page, sitemap and redirects |
| `npm test` | Checks links, anchors, images, headings, metadata and language parity |
| `npm run images` | Regenerates AVIF and WebP (needs `npm i --no-save sharp`) |
| `npm run og` | Regenerates share images and icons (needs `sharp` and `playwright-core`) |

After editing anything in `src`, run `npm run build && npm test` and commit the result.
